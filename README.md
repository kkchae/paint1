# 그림판 (MFC)

Windows 11 그림판과 비슷한 기능을 하는 MFC 기반 그림 편집기입니다.

## 빌드

- Visual Studio 2022 (v143), "C++를 사용한 데스크톱 개발" + MFC 구성 요소
- `sw_paint.sln`을 열고 빌드하거나, 명령줄에서:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Professional\MSBuild\Current\Bin\MSBuild.exe" sw_paint.sln /p:Configuration=Release /p:Platform=x64
```

결과물: `x64\Release\sw_paint.exe` (MFC 정적 링크라 단독 실행 가능)

## 기능

| 분류 | 내용 |
|---|---|
| 파일 | 새로 만들기, 열기(PNG/JPEG/BMP/GIF/TIFF/ICO), 저장/다른 이름으로 저장, 끌어다 놓기로 열기, 명령줄 인수로 열기, 저장 안 한 변경 확인 |
| 선택 | 사각형 선택, 자유 형식 선택, 이동(Ctrl+끌기는 복제), 핸들로 크기 조정, 방향키 이동, 모두 선택, 삭제, 투명 선택 |
| 이미지 | 자르기, 크기 조정 및 기울이기(백분율/픽셀, 비율 유지), 90°/180° 회전, 상하/좌우 대칭, 색 반전, 캔버스 크기(이미지 속성), 지우기, 캔버스 가장자리 핸들로 크기 변경 |
| 도구 | 연필, 채우기, 텍스트(글꼴·크기·굵게·기울임·밑줄·배경 채우기), 지우개, 색 선택, 돋보기 |
| 브러시 | 브러시, 캘리그라피 1·2, 에어브러시, 유화 브러시, 크레용, 마커, 자연스러운 연필, 수채화 브러시 (반투명 브러시는 한 획 안에서 겹쳐도 진해지지 않음) |
| 도형 | 선, 곡선, 타원, 사각형, 둥근 사각형, 다각형, 삼각형, 직각 삼각형, 마름모, 오각형, 육각형, 화살표 4종, 별 3종, 설명선 3종(둥근 사각형·타원형·구름 모양), 하트, 번개 — 그린 뒤 확정 전까지 이동/크기 조정 가능, Shift로 정사각형/45° 고정, 윤곽선·채우기 옵션 |
| 곡선 | 끌어서 선을 긋고 → 한 번 끌어 휘고 → 한 번 더 끌어 휘면 확정 (Esc/Enter로 중간 확정) |
| 다각형 | 끌어서 첫 변 → 클릭할 때마다 꼭짓점 추가 → 시작점 클릭 또는 두 번 클릭으로 닫기, Backspace로 마지막 꼭짓점 취소 |
| 크기 | 굵기 슬라이더 1~100px (연필·브러시·지우개·도형마다 따로 기억, 휠/Ctrl+] / Ctrl+[로 조절) |
| 색 | 색 1/색 2(왼쪽/오른쪽 버튼), 20색 팔레트, 사용자 지정 색 10칸, 색 편집 대화 상자 |
| 보기 | 확대/축소(12.5%~800%, Ctrl+휠, 상태 표시줄 슬라이더와 −/+), 창에 맞추기, 눈금자(커서 위치 표시), 눈금선, 다크 모드(처음에는 Windows 앱 모드를 따름, 설정은 저장됨), 상태 표시줄(커서 위치·선택 크기·이미지 크기·배율) |
| 편집 | 실행 취소/다시 실행(40단계), 잘라내기/복사/붙여넣기(클립보드 비트맵) |

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+N / O / S, Ctrl+Shift+S | 새로 만들기 / 열기 / 저장, 다른 이름으로 저장 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+X / C / V / A, Del | 잘라내기 / 복사 / 붙여넣기 / 모두 선택, 선택 영역 삭제 |
| Ctrl+W, Ctrl+E | 크기 조정 및 기울이기, 이미지 속성 |
| Ctrl+Shift+X / I / N / W | 자르기 / 색 반전 / 이미지 지우기 / 색 1·2 바꾸기 |
| Ctrl+PgUp / PgDn, Ctrl+1, Ctrl+0 | 확대 / 축소, 100%, 창에 맞추기 |
| Ctrl+G, Ctrl+R | 눈금선, 눈금자 |
| Ctrl+] / Ctrl+[ | 굵게 / 가늘게 |
| Ctrl+B / I / U (텍스트 입력 중) | 굵게 / 기울임꼴 / 밑줄 |
| Esc, Enter | 선택 영역·도형·텍스트 확정 |

## 소스 구성

| 파일 | 역할 |
|---|---|
| `PaintApp.cpp` | 애플리케이션 진입점 (GDI+ 초기화, 명령줄 처리) |
| `MainFrm.*` | 프레임 창 — 파일 명령, 제목, 상태 표시줄, 명령 라우팅 |
| `ToolPanel.*`, `PanelIcons.cpp` | Windows 11 스타일 상단 도구 패널 (GDI+로 그린 아이콘) |
| `CanvasWnd.*` | 캔버스 — 확대/스크롤, 화면 합성, 실행 취소, 파일 입출력 |
| `CanvasInput.cpp` | 마우스/키보드, 붓 획, 채우기, 도형, 선택 영역, 텍스트 편집 |
| `CanvasCmds.cpp` | 메뉴/패널 명령 처리 (클립보드, 이미지 변환, 색, 글꼴) |
| `Bitmap32.*` | 32비트 DIB 래퍼 (자르기·회전·대칭·크기 조정·기울이기) |
| `Shapes.*` | 도형 기하 (GDI 그리기 + GDI+ 아이콘 경로) |
| `Dialogs.*` | 크기 조정/기울이기, 이미지 속성 대화 상자 |
| `Theme.*` | 밝은/어두운 테마 색, 제목 표시줄·팝업 메뉴·스크롤 막대 다크 모드 |
| `StatusBarEx.*` | 테마에 맞춰 그리는 상태 표시줄과 확대/축소 슬라이더 |

## 알려진 제한

- 다크 모드에서도 대화 상자(열기/저장, 크기 조정, 글꼴, 색 편집)는 밝은 테마로 표시됩니다.
- 메뉴 표시줄과 팝업 메뉴의 다크 모드는 Windows의 문서화되지 않은 API를 사용합니다. 지원하지 않는 Windows 버전에서는 밝게 표시됩니다.
- Windows 설정에서 "제목 표시줄에 강조 색 표시"가 켜져 있으면 제목 표시줄은 강조 색을 유지합니다.
