# 그림판 (MFC)

Windows 11 그림판과 비슷한 기능을 하는 MFC 기반 그림 편집기입니다.

## 빌드

- Visual Studio 2022 (v143), "C++를 사용한 데스크톱 개발" + MFC 구성 요소
- `sw_paint.sln`을 열고 빌드하거나, 명령줄에서:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Professional\MSBuild\Current\Bin\MSBuild.exe" sw_paint.sln /p:Configuration=Release /p:Platform=x64
```

결과물: `x64\Release\sw_paint.exe` (MFC 정적 링크라 단독 실행 가능)

## 공유 캔버스 사용 가이드

여러 그림판이 하나의 캔버스를 함께 편집합니다. 한 사람이 **호스트**(서버)가 되어 캔버스를 공유하고, 나머지는 **참가자**(클라이언트)로 초대 키를 받아 접속합니다. 최대 16명까지 참가할 수 있습니다.

### 준비

- 모든 PC가 **같은 네트워크**(같은 공유기, 사내망 등)에 있어야 합니다. 인터넷 너머의 PC와 공유하려면 호스트 쪽 공유기에서 포트 포워딩(기본 52700/TCP)이 필요합니다.
- 모든 사람이 같은 버전의 그림판을 사용해야 합니다. 버전이 다르면 참가가 거부됩니다.

### 1. 공유 시작하기 (호스트)

1. 함께 그릴 그림을 열거나 새로 만듭니다. 이 그림이 공유 캔버스가 됩니다.
2. 메뉴에서 **공유 → 공유 시작 (호스트)** 를 선택합니다.
3. 대화 상자를 채우고 **공유 시작** 을 누릅니다.
   - **내 아이디**: 다른 사람에게 보일 이름 (1~20글자)
   - **네트워크 주소**: 참가자가 접속할 이 PC의 주소. 보통 `192.168.x.x` 같은 사내/공유기 주소를 고릅니다. `127.0.0.1`은 이 PC 안에서만 테스트할 때 씁니다.
   - **포트**: 기본값 52700. 사용 중이면 다음 번호를 자동으로 씁니다.
4. 처음 시작할 때 **Windows 방화벽 허용 창**이 나타나면 "개인 네트워크"에 대해 허용해 주세요. 허용하지 않으면 다른 PC가 접속할 수 없습니다.
5. 오른쪽에 **공유 캔버스 패널**이 열리고 **초대 키**(예: `FW00-00ED-VK5E-A557-9JDP-BNPE`)가 표시됩니다. 키는 클립보드에도 복사되어 있으니 메신저 등으로 참가자에게 보내 주세요. 다시 복사하려면 패널의 **복사** 버튼이나 **공유 → 초대 키 복사** 를 사용합니다.

> 초대 키에는 호스트 주소와 일회용 비밀값이 들어 있습니다. 공유를 새로 시작할 때마다 키가 바뀌며, 이전 키로는 접속할 수 없습니다.

### 2. 참가하기 (참가자)

1. 호스트에게 받은 초대 키를 복사합니다.
2. 메뉴에서 **공유 → 공유 캔버스 참가** 를 선택합니다. 클립보드에 초대 키가 있으면 자동으로 채워집니다.
3. **내 아이디** 를 입력하고 **참가** 를 누릅니다. 이미 참가한 사람과 같은 아이디는 쓸 수 없습니다(대소문자 구분 없음).
4. 지금 그림에 저장하지 않은 변경이 있으면 저장할지 묻습니다. 참가하면 **내 그림은 호스트의 그림으로 바뀝니다.**
5. 연결되면 호스트의 캔버스가 나타나고, 제목 표시줄에 `[공유 중 · 참가]` 가 표시됩니다.

### 3. 함께 그리기

- **그리기**: 모든 도구(연필, 브러시, 도형, 텍스트, 채우기, 선택 영역 이동, 회전·크기 조정 등)를 평소처럼 사용합니다. 바뀐 부분이 약 0.06초마다 다른 사람에게 전달됩니다.
- **동시에 같은 곳을 고친 경우**: 호스트에 나중에 도착한 편집이 위에 그려지며, 모든 사람의 화면이 같은 결과로 맞춰집니다.
- **다른 사람의 커서**: 캔버스 위에 참가자별 색 화살표와 아이디가 표시됩니다. 마우스가 캔버스 밖으로 나가면 사라집니다.
- **실행 취소 (Ctrl+Z)**: 내가 한 작업만 되돌리며, 그 결과가 모두에게 공유됩니다. 다른 사람이 그린 부분은 지워지지 않습니다. 단, 다른 사람이 내 그림 위에 겹쳐 그린 부분은 되돌린 결과에 덮어써질 수 있습니다.
- **캔버스 크기 변경**: 자르기, 회전, 크기 조정, 이미지 속성, 새로 만들기, 열기는 모든 사람의 캔버스에 그대로 반영됩니다. 이때 크기를 바꾼 사람을 뺀 나머지 사람들의 실행 취소 기록이 초기화됩니다.
- **저장**: 각자 **파일 → 저장** 으로 현재 공유 캔버스를 자기 PC에 저장할 수 있습니다.

### 4. 채팅과 참가자 목록

- 오른쪽 **공유 캔버스 패널**에 연결 상태, 초대 키(호스트만), 참가자 목록, 채팅이 표시됩니다.
- 아래 입력창에 메시지를 쓰고 **Enter** 또는 **보내기** 를 누르면 모든 참가자에게 전달됩니다.
- 누가 참가하거나 나가면 채팅에 안내가 표시됩니다.
- 패널은 오른쪽 위 **×** 나 **공유 → 공유 패널 표시** 로 숨기거나 다시 열 수 있습니다. 숨겨 둔 상태에서 새 메시지가 오면 자동으로 다시 열립니다.

### 5. 공유 끝내기

- **공유 → 공유 끝내기 / 나가기** 를 선택합니다.
- 호스트가 공유를 끝내거나 그림판을 닫으면 모든 참가자의 연결이 끊어집니다(참가자에게 안내가 표시됨). 참가자의 캔버스는 마지막 상태로 남아 있으므로 필요하면 저장하세요.
- 참가자가 나가도 공유는 계속되며, 나머지 사람은 계속 함께 그릴 수 있습니다.

### 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "초대 키가 올바르지 않습니다" | 키를 빠짐없이 붙여넣었는지 확인하세요. `-` 와 대소문자는 상관없습니다. |
| "호스트에 연결하지 못했습니다" | ① 같은 네트워크인지 ② 호스트가 공유 중인지 ③ 호스트 PC의 방화벽에서 그림판이 허용되었는지 ④ 호스트가 `127.0.0.1` 을 고르지 않았는지 확인하세요. |
| "초대 키가 맞지 않습니다" | 호스트가 공유를 다시 시작해 키가 바뀌었습니다. 새 키를 받아 주세요. |
| "'아이디' 아이디로 이미 참가한 사용자가 있습니다" | 다른 아이디로 다시 참가하세요. |
| "참가 인원이 가득 찼습니다" | 한 캔버스에는 호스트를 포함해 16명까지 참가할 수 있습니다. |
| "호스트와의 연결이 끊어졌습니다" | 호스트가 공유를 끝냈거나 네트워크가 끊어졌습니다. 새 초대 키로 다시 참가하세요. |

### 한 PC에서 시험해 보기

1. 그림판을 두 개 실행합니다.
2. 첫 번째 창에서 **공유 시작** 을 누르고 네트워크 주소로 `127.0.0.1 (이 PC에서만)` 을 고릅니다. 이때는 방화벽 창이 나타나지 않습니다.
3. 두 번째 창에서 **공유 캔버스 참가** 를 누르면 초대 키가 자동으로 채워집니다. 다른 아이디를 넣고 참가합니다.

### 동작 방식

| 항목 | 방식 |
|---|---|
| 연결 | TCP 직접 연결 (같은 네트워크, 인터넷은 포트 포워딩 필요). `127.0.0.1`을 고르면 이 PC에서만 테스트 가능 |
| 초대 키 | 호스트 IPv4 + 포트 + 무작위 비밀값 8바이트 + 검사값을 Base32로 인코딩. 비밀값이 맞아야 참가 가능 |
| 그림 동기화 | 편집 후 60ms마다 바뀐 사각형 영역의 픽셀을 압축해 전송. 호스트가 순서를 정해 보낸 사람 포함 모두에게 다시 보내므로 모든 캔버스가 같은 결과가 됨. 캔버스 크기가 바뀌면 전체 그림 전송 |
| 실행 취소 | 내 실행 취소 결과도 공유됨. 다른 사람의 편집은 실행 취소 기록에도 반영되어 내 실행 취소로 지워지지 않음 (같은 영역을 겹쳐 고친 경우는 덮어쓸 수 있음) |
| 커서 | 다른 참가자의 마우스 위치를 색 화살표와 아이디로 표시 |
| 채팅 | 오른쪽 공유 패널에서 참가자 목록과 채팅 (Enter로 보내기) |

통신은 암호화되지 않으므로 신뢰할 수 있는 네트워크에서 사용하세요.

## 알려진 제한

- 다크 모드에서도 대화 상자(열기/저장, 크기 조정, 글꼴, 색 편집)는 밝은 테마로 표시됩니다.
- 메뉴 표시줄과 팝업 메뉴의 다크 모드는 Windows의 문서화되지 않은 API를 사용합니다. 지원하지 않는 Windows 버전에서는 밝게 표시됩니다.
- Windows 설정에서 "제목 표시줄에 강조 색 표시"가 켜져 있으면 제목 표시줄은 강조 색을 유지합니다.
